Technical Requirements

 Build using React + TypeScript.

 Use Tailwind CSS for styling.

 Create reusable components.

 Use responsive layouts for desktop, tablet, and mobile.

 Organize the code with clear folder structure and clean architecture.

 Include placeholder integrations for Speech-to-Text, AI extraction, PDF generation, WhatsApp Business API, and database APIs so they can be connected later.

 Follow accessibility best practices and modern UI/UX principles.

The final result should look like a polished enterprise SaaS product that is intuitive for sales executives, visually engaging, and ready to integrate with AI and backend service
